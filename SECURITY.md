# Security Policy — Lumi Addons Ecosystem

## Supported Versions

Currently, the `main` branch of Lumi Addons receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within any Lumi Addon, please do NOT report it in a public issue. Use GitHub's private vulnerability reporting feature or contact maintainers via `security@lumi-devs.org`.

## Addon Execution Safety

> [!WARNING]
> Addons execute within the Lumi bot runtime environment. Ensure all installed addons come from trusted sources and pass static analysis checks.
